## 📥 Guide d'installation — Menu Pratique (Édition Tranchent)

## ⚡ Qu’est-ce que c’est ?

**Menu Pratique — Édition Tranchent**  
Un **menu rapide, stylé et puissant** pour lancer facilement tes applis préférées, faire des captures d'écran, installer des logiciels et bien plus !

---

## 🖥️ Fonctionnalités

- 🚀 Lance Discord, Telegram, Fortnite, Minecraft en 1 clic
- 🖼️ Capture tes screenshots et gère-les facilement
- ⏲️ Minuteur rapide 60 min intégré
- 🛠️ Installe rapidement mes logiciels recommandés
- 🎨 Interface claire avec icônes propres

---

## 🔧 Installation (très simple)

1️⃣ Télécharge le **fichier `MPET-Setup.bat`** (fourni par Tranchent)

2️⃣ **Crée un dossier vide** → Mets le fichier `.bat` dedans

3️⃣ **Double-clique** sur `MPET-Setup.bat`

4️⃣ Le script fait tout pour toi :  
✅ Installe Python (si besoin)  
✅ Télécharge le projet depuis GitHub  
✅ Installe tout automatiquement  
✅ Crée les dossiers nécessaires  
✅ Lance le programme

5️⃣ **Profite !**  
Le menu s'ouvre et tu peux tout utiliser.
